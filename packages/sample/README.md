# Package consumer

Package consumer. A runnable test application of the `jrjs` project.

Emulates what could be run from `jrjs-template` derived repos, consuming the `jrjs` dependency.

## Run

From the repo's top level:

`npm run start`

It will prebuild and run `consumer/sys/index.js`, launching a server, as configured in `consumer/sys/config.js` by default.
